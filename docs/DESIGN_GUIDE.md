# 버건디와 카고색으로 만든 디자인 읽기

이번 변경은 화면 디자인입니다. 실습은 기존 27개이며 정답·보상·API·D1 구조는 그대로 사용합니다.

## 1. 색상에 역할을 주기

| 색상 | CSS 변수 | 사용하는 곳 |
| --- | --- | --- |
| 버건디 `#7b263f` | `--brand` | 메인 배너, 선택된 메뉴, 시작·제출 버튼 |
| 연한 버건디 `#f5eaee` | `--brand-soft` | 현재 단계 안내, 선택한 답변 |
| 카고색 `#626b46` | `--cargo` | 학습 상태, 보조 아이콘, 배너의 뒤 패널 |
| 연한 카고색 `#eff1e8` | `--cargo-soft` | 용어 설명, 학습 단계, 비교 결과 |
| 검정 `#191b19` | `--ink` | 본문과 제목. 사이드바와 코드 창은 비슷한 어두운 색 |
| 흰색 `#ffffff` | 요소의 `background` | 실습 카드, 입력창, 읽는 영역 |

CSS는 `index.html`의 `<style>` 마지막에 있는 `Burgundy / cargo design system` 주석부터 읽으면 됩니다. 게임 안의 공격·정상 패킷처럼 의미를 구별하는 색은 해당 실습의 설명을 따릅니다.

```css
:root {
  --brand: #7b263f;
  --cargo: #626b46;
  --ink: #191b19;
}
```

같은 색을 여기저기 쓰더라도 이름으로 관리하면 역할을 유지하기 쉽습니다. `.btn`은 버건디, `.briefing`은 카고색 계열, `.sidebar`는 검정, `.mission-card`는 흰색입니다.

## 2. 그림자를 여러 겹 사용하기

```css
--shadow-card:
  0 2px 3px #1d22100a,
  0 12px 30px #1d22100b;
```

`box-shadow`는 가로 이동, 세로 이동, 흐림 크기, 색상 순서입니다. 첫 그림자는 카드 가까이에 생기는 짧은 그림자이고, 두 번째는 주변으로 퍼지는 그림자입니다. 둘을 함께 쓰면 카드가 배경에서 살짝 떠 보입니다.

`#1d22100b`의 마지막 두 자리 `0b`는 투명도입니다. 불투명하고 진한 검정을 바로 쓰는 것보다 흐린 그림자를 겹치는 편이 화면을 덜 무겁게 만듭니다.

- `--shadow-sm`: 보조 패널의 낮은 높이.
- `--shadow-card`: 실습 카드의 기본 높이.
- `--shadow-lift`: 마우스를 올렸을 때의 높이.

## 3. 메인 배너의 겹친 패널

```text
.hero-scene
  ├─ .scene-back                  카고색 뒤 패널
  ├─ .hero-preview.beginner-preview  흰색 학습 순서
  │    ├─ .visual-window-bar      작은 창 머리글
  │    └─ .scene-shield           방패 SVG
  └─ .scene-stamp                 연습 안내
```

`.scene-back`은 `position: absolute`로 뒤에 배치하고 `rotate(8deg)`로 기울입니다. 앞 패널은 `rotate(-4deg)`를 적용해 두 층의 방향을 다르게 합니다. 테두리의 밝은 선과 아래 그림자가 두께를 보여줍니다.

방패와 체크 아이콘은 HTML의 SVG 경로입니다. 별도의 큰 이미지 파일을 내려받지 않아도 선명하게 표시됩니다. 장식 아이콘에는 `aria-hidden="true"`를 붙여 보조기기가 장식을 중복 읽지 않게 했습니다. 실제 학습 순서는 텍스트로 남겨 두었습니다.

메인 배너의 `radial-gradient`는 오른쪽 위의 부드러운 빛을, `linear-gradient`는 버건디 재질을 만듭니다. `:before`의 가는 격자와 `:after`의 원은 HTML 내용을 더하지 않는 배경 장식입니다.

## 4. 눌리는 버튼과 떠오르는 카드

```css
.btn:active:not(:disabled) {
  transform: translateY(2px);
  box-shadow: inset 0 1px 0 #ffffff1c, 0 1px 0 #4e1829;
}
```

버튼을 누르면 아래로 2px 움직이고 아래 그림자가 짧아집니다. 이 두 변화가 버튼이 눌리는 느낌을 줍니다.

실습 카드와 추천 카드는 마우스를 올리면 위로 4px 움직입니다. 이 효과는 마우스를 사용할 수 있고 사용자가 동작 감소를 요청하지 않은 환경에만 적용합니다. 키보드로 선택한 곳에는 별도의 포커스 테두리가 보입니다.

`renderMissions()`에서 완료한 카드에 `completed` 클래스를 붙였습니다. CSS의 `.mission-card.completed`는 카고색 테두리와 아이콘을 적용합니다. 완료 여부를 계산하는 기존 규칙이나 점수는 바꾸지 않습니다.

## 5. 모바일에서는 읽는 순서를 유지하기

- 작은 화면에서는 겹친 장식 패널 `.hero-scene`을 숨겨 제목·설명·시작 버튼이 먼저 보입니다.
- 추천 실습은 세 열에서 한 열로 바뀝니다. 좁은 화면의 실습 라이브러리도 한 열입니다.
- 주 메뉴는 화면 아래의 검정 내비게이션으로 옮겨집니다.
- 실습 창의 본문은 스크롤하고 상단 진행 표시와 아래 제출 버튼은 기존처럼 남습니다.
- `prefers-reduced-motion: reduce`에서는 이동 효과와 전환을 줄입니다.

```css
@media (max-width: 760px) {
  .hero-scene { display: none; }
}
```

미디어 쿼리는 화면 조건에 맞을 때만 안쪽 규칙을 적용합니다. 같은 내용이라도 휴대폰에서는 장식보다 읽기와 조작 공간이 더 필요합니다.

## 6. 직접 바꿔볼 작은 연습

1. `--shadow-card`의 두 번째 그림자 흐림 크기를 `30px`에서 `20px`로 바꾸고 떠 있는 느낌을 비교하세요.
2. `.scene-back`의 `rotate(8deg)`를 `rotate(4deg)`로 바꾸고 겹침의 차이를 보세요.
3. `.mission-card`의 `border-radius:16px`를 `12px`로 바꾸고 인상을 비교하세요.

한 번에 한 값씩 바꾸고 PC와 모바일을 모두 확인하세요. 색을 바꿀 때에는 밝은 배경의 글씨와 어두운 배경의 글씨가 잘 읽히는지 함께 봅니다.
